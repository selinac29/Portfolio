Overview

VendorHub is a location-based web platform for discovering independent vendors, pop-up markets and micro-events near Vancouver. Built with React on the frontend, Node.js and Express on the backend, and MongoDB for data storage. It pulls event listings from Vancouver Open Data and the Google Maps API. The platform also supports three distinct user roles with different levels of access.
